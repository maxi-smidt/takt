Foundations

Color

Every color a component uses comes from the --ui-* contract in tokens.css — never a raw hex. This page is rendered with the real Fleet Registry mapping (theme-fleet.css); the Pi timer app maps the same nine roles onto its own blue-black palette instead. See "Two surfaces, one contract" in readme.md.
